# Contributing

## Guidelines

1. Fork the repository.
2. Build and run by following [Getting Started](docs/getting-started.md).

3. Create a new branch for your change:
   ```bash
   git checkout -b feature/your-feature
   ```
4. Create and activate a virtual environment:
```bash 
python3 -m venv venv
source venv/bin/activate
``` 

### PRs

- One change for each PR and explain what changed and why



### Reporting Bugs
If you find a bug, please provide enough information to reproduce it.

- Describe the bug and what you expected to happen.
- Include your operating system and Python version.
- Check existing issues before opening a new one.
